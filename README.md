# fingerspelling-map-annotation

手話文章動画に含まれる指文字区間のアノテーションツールと、アノテーションの規則。

## 使い方

```bash
pip install -r requirements.txt

# フォルダ内の動画を番号順に1本ずつ開く（完了済みは飛ばし、途中のものは続きから）
python annotate.py --videos Video/文章 --out annotations --annotator yamada

# 検査と集約
python validate.py --out annotations --export annotations_all.csv
```

### 開く動画の指定

`annotate.py` と `label_frames.py` のどちらでも、次の方法で開く動画を選べます。

| 指定方法 | 例 | 開く順番 | 完了済みの動画 |
|---|---|---|---|
| フォルダ | `--videos Video/文章` | ファイル名の番号順 | 飛ばす（`--redo` で開く） |
| ファイル | `--files Video/文章/3.mp4 Video/文章/7.mp4` | 指定した順 | 開く |
| リスト | `--list videos.txt` | 書いた順 | 開く |
| 選択画面 | `--pick` | 選んだ順 | 開く |
| フォルダ内の1本 | `--videos Video/文章 --only 3.mp4` | ― | 開く |

`--files`・`--list`・`--pick` は組み合わせられ、同じ動画を重ねて指定しても1回だけ開きます。
リストのテキストファイルは1行に1つ動画のパスを書き、`#` 以降はコメントです。相対パスはリストファイルのある場所が基準です。

```
# 1回目の作業分
Video/文章/3.mp4
Video/文章/7.mp4
/Users/x21095xx/Desktop/別の動画/sentence_12.mp4
```

保存ファイルは動画のファイル名で決まるため、別のフォルダに同じ名前の動画があるときは止まります。名前を変えるか、`--out` を分けてください。
`--pick` は Python の tkinter を使います。使えない環境では `--files` か `--list` を使ってください。

### キー操作（動画のウィンドウを選択した状態で押す）

| キー | 操作 |
|---|---|
| space | 再生 / 一時停止 |
| d / a | 1フレーム進む / 戻る |
| D / A（c / z） | 10フレーム進む / 戻る |
| ] / [ | 再生速度を上げる / 下げる（0.1〜1倍） |
| s / e | 開始 / 終了フレームを現在位置にする |
| Enter（k） | 区間を確定し、**ターミナル**で文字列を入力 |
| x | 現在位置を含む区間を削除 |
| u | 最後に追加した区間を取り消す |
| g | 次の区間の先頭へ移動 |
| n | この動画を**完了**にして次へ（すべて付けたか確認される） |
| p | 完了にせず次へ |
| q | 保存して終了 |
| h | 操作説明を表示 |

画面下のタイムラインで、緑が確定した区間、黄が指定中の範囲、赤が現在位置です。
現在位置が区間の中にあると、映像が緑の枠で囲まれます。
日本語は画面に表示できないため、区間の文字列はターミナルに表示されます。

## フレーム単位のラベル付け（label_frames.py）

動画を再生しながら、各フレームに「1 = 指文字」「2 = それ以外」を付ける。
キーで選んだブラシが、再生やコマ送りで通過したフレームに塗られ、押し直すまで続く。

```bash
python label_frames.py --videos Video/文章 --out annotations_frames --annotator yamada
```

| キー | 操作 |
|---|---|
| 1 / 2 | ブラシ「指文字」/「それ以外」（現在のフレームから塗る） |
| 3 | ブラシ「消しゴム」（未定に戻す） |
| 0 | ブラシを離す（塗らずに見返す） |
| space, d / a, D / A, ] / [ | 再生・コマ送り・速度（annotate.py と同じ） |
| u | 直前の操作を取り消す（再生中に塗った分は1フレームずつ） |
| g | 次の未定のフレームへ移動 |
| n / p / q / h | 完了して次へ / 完了せず次へ / 終了 / 説明 |

タイムラインは緑 = 指文字、橙 = それ以外、灰 = 未定で、映像の枠の色が現在のフレームのラベルを表す。
出力は `annotations_frames/<動画名>.csv`（frame, label, annotator）と `_progress.csv`。
人の反応は再生より遅れるので、境界は一時停止してコマ送りで確認してから切り替える。
区間の境界と文字列を正確に付けるのは annotate.py、学習用の「指文字かどうか」を素早く付けるのは label_frames.py と使い分ける。

## 出力

```
annotations/
  _progress.csv        動画ごとの状態（done / in_progress）、区間数、フレーム数、fps、作業者
  sentence_001.csv     区間ごとに video, start_frame, end_frame, text, annotator
  ...
```

- フレーム番号は、動画を先頭から順に読んだときの番号（0 始まり）で、骨格抽出と同じ数え方です。
- `start_frame` と `end_frame` は両端を含みます。
- 変更するたびに自動保存されます。

## アノテーションの規則

1. **1本の動画の指文字区間は、すべて付ける。**
   印のないフレームは「指文字ではない」とみなして評価に使うため、付け忘れは評価を不当に下げます。
   すべて付け終えたら `n` で完了にします。完了していない動画は評価に使いません。
   指文字が1つもない動画も、区間0個のまま完了にします。
2. **開始**：最初の文字の手の形ができたフレーム。
3. **終了**：最後の文字の手の形（動きを伴う文字は動き）が終わり、形が崩れ始める直前のフレーム。
4. 指文字の前後の、手を構える・下ろす遷移動作は区間に含めない。
5. 連続する2つの指文字の単語の間に、手型が崩れる・通常の手話が入るなどの切れ目があれば、別の区間にする。
6. **文字列**は、表現された文字をひらがなで入力する。
   - 濁音・半濁音・拗音・促音は、表現されたとおりに「が」「ぱ」「ゃ」「っ」と入力する。
   - 長音は「ー」で入力する。
   - 表現が崩れていて判別しにくい文字も、表現者が意図した文字を入力する。判断に自信がない区間は、動画名とフレーム番号を `notes.md` に記録しておく。
7. 境界の判断に迷ったら、スロー再生（`[`）とコマ送り（`a` / `d`）で確認する。

境界の付け方の揺れを評価するため、一部の動画は別の作業者（または同じ作業者が時間をおいて）にもう一度付けてもらい、一致度を確認します。その際は `--annotator` を変え、`--out` を別のフォルダにします。
