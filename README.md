# fingerspelling-annotation

手話文章動画に含まれる指文字区間のアノテーションツールと、アノテーションの規則。

## 使い方

```bash
pip install -r requirements.txt

# フォルダ内の動画を番号順に1本ずつ開く（完了済みは飛ばし、途中のものは続きから）
python annotate.py --videos Video/文章 --out annotations --annotator yamada

# 検査と集約
python validate.py --out annotations --export annotations_all.csv
```

### キー操作（動画のウィンドウを選択した状態で押す）

| キー | 操作 |
|---|---|
| space | 再生 / 一時停止 |
| d / a | 1フレーム進む / 戻る |
| D / A（c / z） | 10フレーム進む / 戻る |
| ] / [ | 再生速度を上げる / 下げる（0.1〜1倍） |
| s / e | 開始 / 終了フレームを現在位置にする |
| Enter（k） | 区間を確定し、**ターミナル**で文字列を入力 |
| x | 現在位置を含む区間を削除 |
| u | 最後に追加した区間を取り消す |
| g | 次の区間の先頭へ移動 |
| n | この動画を**完了**にして次へ（すべて付けたか確認される） |
| p | 完了にせず次へ |
| q | 保存して終了 |
| h | 操作説明を表示 |

画面下のタイムラインで、緑が確定した区間、黄が指定中の範囲、赤が現在位置です。
現在位置が区間の中にあると、映像が緑の枠で囲まれます。
日本語は画面に表示できないため、区間の文字列はターミナルに表示されます。

## 出力

```
annotations/
  _progress.csv        動画ごとの状態（done / in_progress）、区間数、フレーム数、fps、作業者
  sentence_001.csv     区間ごとに video, start_frame, end_frame, text, annotator
  ...
```

- フレーム番号は、動画を先頭から順に読んだときの番号（0 始まり）で、骨格抽出と同じ数え方です。
- `start_frame` と `end_frame` は両端を含みます。
- 変更するたびに自動保存されます。

## アノテーションの規則

1. **1本の動画の指文字区間は、すべて付ける。**
   印のないフレームは「指文字ではない」とみなして評価に使うため、付け忘れは評価を不当に下げます。
   すべて付け終えたら `n` で完了にします。完了していない動画は評価に使いません。
   指文字が1つもない動画も、区間0個のまま完了にします。
2. **開始**：最初の文字の手の形ができたフレーム。
3. **終了**：最後の文字の手の形（動きを伴う文字は動き）が終わり、形が崩れ始める直前のフレーム。
4. 指文字の前後の、手を構える・下ろす遷移動作は区間に含めない。
5. 連続する2つの指文字の単語の間に、手型が崩れる・通常の手話が入るなどの切れ目があれば、別の区間にする。
6. **文字列**は、表現された文字をひらがなで入力する。
   - 濁音・半濁音・拗音・促音は、表現されたとおりに「が」「ぱ」「ゃ」「っ」と入力する。
   - 長音は「ー」で入力する。
   - 表現が崩れていて判別しにくい文字も、表現者が意図した文字を入力する。判断に自信がない区間は、動画名とフレーム番号を `notes.md` に記録しておく。
7. 境界の判断に迷ったら、スロー再生（`[`）とコマ送り（`a` / `d`）で確認する。

境界の付け方の揺れを評価するため、一部の動画は別の作業者（または同じ作業者が時間をおいて）にもう一度付けてもらい、一致度を確認します。その際は `--annotator` を変え、`--out` を別のフォルダにします。
